# Bone Tumors: Drag & Drop

Match each bone tumor to its case vignette, benign/malignant status, radiography, histomorphology, genetics and treatment.
Part of the free Secondary Active Transport study tools from Active Transport (https://activetransport.app).

Edit `_build.py` (the table) or `_template.html` (the game), then run `py _build.py` to rebuild `index.html`.
